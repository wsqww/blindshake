# 摇摇瞎选

摇一摇手机随机决策的微信小程序:把犹豫不决交给随机——吃什么、去哪玩、做哪个都行。纯本地运行,无后端,数据存于微信本地存储。

微信扫一扫,直接打开小程序:

## 运行

1. 打开微信开发者工具,导入本目录(`blindshake/`);
2. `project.config.json` 中的 `appid` 为占位(`touristappid`),替换为自己的小程序 AppID;
3. 首页可真机摇一摇,也可点底部「不方便摇?点这里也行」触发(开发者工具调试用)。

## 功能

- **分组管理**:多分组增删改与切换(至少保留一个分组),首页摇一摇仅从选中分组随机;删除分组连带清理其选项与确定记录;
- **候选选项**:单个添加、点击名称修改、多行粘贴批量导入(重名自动跳过,每组上限 20 个),均在当前分组内维护;
- **加权随机**:每个选项初始权重 1.0,结果弹窗点「减少推荐」权重减半(下限 0.1),管理页可视化并支持一键恢复;
- **冷却(二选一模式,默认按次数)**:点「确定选择」才占用——按次数:该选项接下来 N 次摇不出现(默认 5,每次摇出结果推进一次);按时间范围:N 天内不出现(默认 7)。冷却可清空解锁;
- **交互**:加速计摇一摇(1.5s 防抖)→ 老虎机滚动选项名 + 庆祝粒子定格 → 结果弹窗(确定选择 / 重新随机 / 减少推荐);连摇 3 次未确定弹柔性提示;候选全部冷却时提供「解锁全部」,每次摇动会推进冷却。

## 结构

```
app.*                 全局配置与样式
pages/shake/          首页:摇一摇 + 老虎机 + 结果弹窗
pages/manage/         管理页:分组 / 选项 / 权重 / 冷却设置
utils/store.js        数据模型与 wx.storage 封装
utils/random.js       可用池过滤 + 加权随机(纯函数)
```
